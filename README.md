# Whitefield Union — Social Intelligence

Interactive, light-theme social media analysis prepared by myPAL Pulze.

Open `index.html` in a browser. It is self-contained and works offline; source links require internet access. No dependencies or analytics trackers.

## Sections
- Overview and publishing-account comparisons
- Engagement, content themes, cadence and searchable post evidence
- Sentiment, intent and source-linked comments
- Qualitative competitor strategy comparison
- Collection coverage and methodology
- Growth opportunities
- Audience register and two-post liker overlap

## Data
The report uses the supplied October 2026 audit: 64 posts, 759 collected comments, 4,971 liker/post pairs and 2,586 observed liker handles. Public handles and comment text are included in the report and source data. Sentiment labels are provisional rules-based classifications. Competitor strategies are sourced qualitative comparisons, not matched performance benchmarks. Collection limits are documented inside the report.

## Build
Edit files in `src/`, then run:

```sh
python3 build.py
```

`index.html` can be served by any static host. Publishing or enabling GitHub Pages is separate from pushing this repository.
